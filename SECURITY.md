# Security

## Reporting a vulnerability

Please report security issues in Orvisign privately to **info@orvisign.com** with the subject "Security". Do not open a public GitHub issue for a vulnerability.

Include the Orvisign version, your operating system and the steps to reproduce. We acknowledge reports and keep you informed until the issue is resolved.

Our information security policy: https://orvisign.com/en/legal/security.html

## Verifying installers

Only install Orvisign from orvisign.com, the Microsoft Store, the official browser stores or the Releases of this repository. Check every download against the `SHA256SUMS` file of its release. macOS installers are signed with Developer ID Installer: EGEROBOT OTOMASYON MUHENDISLIK PROJE DANISMANLIK SANAYI VE TICARET LIMITED SIRKETI (9S8KV52JV4) and notarized by Apple.

# Güvenlik

Orvisign'daki güvenlik açıklarını lütfen **info@orvisign.com** adresine "Güvenlik" konusuyla, gizli olarak bildirin; açık için herkese açık GitHub kaydı açmayın. Orvisign sürümünü, işletim sisteminizi ve adımları yazın. Kurulum dosyalarını yalnız orvisign.com'dan, Microsoft Store'dan, resmî tarayıcı mağazalarından ya da bu deponun sürümlerinden indirin ve `SHA256SUMS` ile doğrulayın.
